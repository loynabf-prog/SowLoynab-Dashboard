Apify-Einrichtung am PC

Sechs Schritte, danach laufen die automatischen Zahlen, das Nachtragen alter Videos und die Lead-Suche über Google Maps. Einmalig, ungefähr 20 Minuten.

3 Seiten: Apify, Supabase, GitHub 1 SQL-Skript 4 Funktionen 2 Zeitpläne
✓

Die Frontend-Korrekturen sind schon live. Dafür musst du nichts tun — nur die App einmal neu laden. Alles unten dreht sich ausschließlich um die Apify-Anbindung.

1

Apify-Konto anlegen und Token kopieren

Wo apify.com

  1. Kostenlos registrieren (oder einloggen).
  2. Oben rechts aufs Profil → Settings → API & Integrations.
  3. Den Personal API token kopieren.
⚠ Der Token ist ein Passwort. Nicht in den Chat einfügen und nicht ins Repo — er gehört nur an die eine Stelle in Schritt 2.
2

Token in Supabase hinterlegen

Wo Supabase → dein Projekt → Edge Functions → Secrets

  1. Add new secret klicken.
  2. Name: APIFY_TOKEN
  3. Value: der Token aus Schritt 1 → speichern.

Dieser eine Token versorgt alle vier Funktionen — mehr Secrets brauchst du hier nicht.

3

Das SQL-Skript ausführen

Wo Supabase → SQL Editor → New query

Ich habe beide offenen Skripte zu einem zusammengefasst, du fügst also nur einmal ein:

  1. Datei öffnen: ALLES_offen_20-21.sql
  2. Auf GitHub rechts über dem Code aufs Kopier-Symbol klicken.
  3. Im SQL Editor einfügen und Run drücken.
✓ Gefahrlos: Das Skript legt Spalten nur an, wenn sie fehlen. Ein zweiter Durchlauf schadet nicht.
4

Die vier Funktionen anlegen

Wo Supabase → Edge Functions → Deploy a new function

Vier Mal dasselbe Muster: Name eintragen, Code von GitHub hineinkopieren, deployen, danach in den Einstellungen der Funktion den Enforce JWT-Schalter setzen.

NameCodeEnforce JWT
refresh-stats index.ts AUS
refresh-account-stats index.ts AUS
apify-lookup index.ts AN
apify-places-search index.ts AN
⚠ refresh-stats gibt es eventuell schon von früher. Dann nicht neu anlegen, sondern öffnen und den Code ersetzen — der Inhalt hat sich geändert (neuer Prüf-Rhythmus: 7 Tage täglich, dann wöchentlich, dann monatlich).
5

Projekt-Kennung und Anon-Key holen

Wo Supabase → Project Settings → API

  1. Project URL ansehen — das Stück zwischen https:// und .supabase.co ist deine Projekt-Kennung.
  2. Den anon public Key kopieren.

Beides brauchst du gleich in Schritt 6. Der Anon-Key ist öffentlich und unkritisch.

6

Die zwei Zeitpläne einrichten

Wo Supabase → SQL Editor → New query

Für jedes der beiden Skripte: Inhalt kopieren, im Text DEIN-PROJEKT-REF und DEIN-ANON-KEY durch deine Werte aus Schritt 5 ersetzen, dann Run.

  1. refresh-account-stats / cron-setup.sql — neu, holt täglich die Follower-Zahlen.
  2. refresh-stats / cron-setup.sql — läuft vielleicht schon. Wenn du unsicher bist: einfach nochmal ausführen.

Prüfen kannst du es mit select * from cron.job; — da sollten beide auftauchen.

Danach: alles Weitere geht vom Handy

Am PC ist nichts mehr zu tun. In der App dann einfach:

  • Kunden-Handles eintragen — Kundenseite → Bearbeiten → Instagram/TikTok. Ab dann kommen Follower und Zahlen von selbst.
  • Altes Video nachtragen — ＋ Neu → 🔗 Nachtragen → Link einfügen → Daten abrufen.
  • Leads aus Google Maps — Leads → 🗺️ Google Maps → Kategorie und Ort wählen.

Kosten: Apify rechnet pro Abruf ab. Die laufende Statistik liegt bei ein paar Euro im Monat, eine komplette Google-Maps-Runde für Münster bei unter 5 $ einmalig.
